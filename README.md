# ✨ إلهام -- Luxury Perfume Experience

Perfume Experience Website is a modern luxury web project that showcases
perfumes with a 3D animated intro, elegant UI, and AI-powered quiz that
recommends the perfect fragrance. Built with HTML, CSS, JavaScript, and
Three.js, it delivers a premium interactive shopping experience.

------------------------------------------------------------------------

## 🌟 Features

-   3D intro experience\
-   Luxury UI design\
-   Perfume catalog (Men & Women)\
-   AI personality quiz recommendation\
-   Smooth animations\
-   Responsive design

------------------------------------------------------------------------

## 🛠️ Tech Stack

HTML, CSS, JavaScript, Three.js

------------------------------------------------------------------------

## 🚀 How to Run

Open index.html in browser.
